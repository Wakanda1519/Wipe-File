# 🗑️ Wipe-File

**Удобный инструмент для автоматизации очистки файлов и директорий.**

![Electron](https://img.shields.io/badge/Electron-Desktop-47848F?style=flat-square&logo=electron&logoColor=white)
![Node.js](https://img.shields.io/badge/Node.js-Backend-43853D?style=flat-square&logo=node.js&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)

**Wipe-File** — это десктопное приложение на Electron, которое позволяет создавать сценарии ("операции") для быстрого удаления мусорных файлов. Забудьте о ручной чистке папок — настройте один раз и удаляйте в один клик.

---

## ✨ Возможности

* Создавайте именованные операции (например, "Очистка логов" или "Сброс кэша").
* Удаление файлов по конкретным расширениям (например, `*.log`, `*.tmp`) внутри указанных папок.
* Возможность удалять конкретные файлы или целые директории.
* Удобный графический интерфейс без необходимости использовать консоль.

---

## 📋 Предварительные требования

Для сборки проекта из исходного кода вам понадобятся:
*   [Node.js](https://nodejs.org/) (версия 16 или выше)
*   npm (обычно идет вместе с Node.js)

---

## 📦 Установка и Сборка

Если вы хотите собрать приложение самостоятельно:

1.  **Скачайте репозиторий:**
    ```bash
    git clone https://github.com/Wakanda1519/Wipe-File.git
    cd Wipe-File
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Соберите проект (Windows):**
    ```bash
    npm run build:win
    ```

4.  **Запуск:**
    Готовый `.exe` файл установщика появится в папке `/dist`.

---

## 🚀 Как пользоваться

Интерфейс приложения интуитивно понятен.

1.  Создайте новую **Операцию** (группу задач).
2.  Добавьте в неё пути к папкам или файлам.
3.  Настройте фильтры (например, "удалять только `.json`").
4.  Нажмите кнопку запуска для очистки.

> 💡 **Подсказка:** Внутри приложения есть встроенная справка. Нажмите кнопку со знаком **(?)** в верхней части интерфейса, чтобы узнать подробности.
